Resume Screening and Candidate Ranking System
This project helps recruiters screen resumes and rank candidates based on how well their resumes match a job description.

Technologies Used
* Python
* Pandas
* Scikit-learn
* TF-IDF
* Cosine Similarity

Features
* Resume Screening
* Candidate Ranking
* Match Percentage Calculation

Workflow
1. Enter Job Description
2. Compare Resumes
3. Calculate Similarity Score
4. Rank Candidates
5. Display Results

Output
The system shows:

* Candidate Name
* Match Score
* Match Percentage
* Rank

Conclusion
This project automates the resume screening process using NLP techniques and helps identify the best candidates for a job role.
